# Visual Hierarchy Rules

Every section must have one primary focal element.

A section may contain:
- One primary statement or visual
- One secondary explanatory layer
- One clear action

Avoid:
- Two equally large headlines
- More than one primary CTA
- More than three visually equal cards
- Multiple competing accent colors
- Equal visual weight across every block

Use:
- Scale for strategic statements
- Position for priority
- Contrast for state
- Spacing for grouping
- Borders only for structure
- Motion only for state transition
