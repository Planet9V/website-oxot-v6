# Mobile Rules for System Visuals

- Do not shrink a complex SVG until labels become unreadable.
- On mobile, replace the side-by-side canvas and evidence panel with:
  1. View selector
  2. Canvas
  3. Selected state summary
  4. Evidence drawer
  5. CTA

- Use horizontal scroll only for:
  - Layer timelines
  - Very wide comparison tables
  - Detailed dependency graphs
  And only with visible affordance and alternate summary.

- Touch targets: minimum 44px preferred.
- Every interactive state must be selectable without drag.
- Never hide crucial state text behind hover.
