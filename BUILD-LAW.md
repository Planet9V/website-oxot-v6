# BUILD LAW — the new OXOT site

Read this before writing a line. Then read the handover documents it names.

---

## 1. What we are building

A new site in `web/`, replacing the previous application entirely. **Next 16.3,
React 19.2, Tailwind 4, Turbopack, no CMS.** Content is typed code.

The owner's directive: *"focus on quality and advanced visualisations and
achieving the best website aligned to the goal ever."* You are not porting. You
are building the best version of this argument that a browser can hold.

## 3. Content is code. Facts come from `src/content/claims.ts`.

Import claims; do not retype facts. Every claim there carries its source,
clearance date, a proof URL, and a recheck date where the world can change it.

**If a fact is not in `claims.ts`, you may not assert it.** Add it there, with
its source, or leave it out. This is aimed at the two most expensive failures of
the previous site, both of which were provenance failures rather than writing
failures: a condemned headline shipping because someone improvised, and eight
surfaces claiming Article 14 "already requires" something 35 days before it
applied — quoted verbatim from a cleared sheet written for a later reader.

**The signature move.** Every page carries one checkable number with its source
one click away, *including the part that is unflattering*. Two independent
reviewers scored the old site highest on exactly this; one tried to disprove it,
summed RVO's table by hand, found every figure exact, and wrote: *"a firm that
hands you the arithmetic that hurts it has earned the two minutes."*
`GRANT.theCostlyTruth` and `CRA.article69` are the models.

## 4. Next 16 is NOT the Next.js you know

Verified against `node_modules/next/dist/docs/` in this project:

- **`middleware.ts` is now `proxy.ts`.** The old convention is deprecated.
- **Async request APIs are fully breaking.** `params`, `searchParams`,
  `cookies()`, `headers()`, `draftMode()` are Promises. The Next 15 synchronous
  compatibility period is **over**. `const { slug } = await props.params`.
- **`PageProps<'/route'>` is a GLOBAL type helper** generated by `next dev` /
  `next build` / `next typegen`. Do not import it. Use the route literal for
  strict param keys: `export default async function Page(props: PageProps<'/cra'>)`.
  Also `LayoutProps` and `RouteContext`.
- **Turbopack is the default builder**, including `next build`.
- Node 20.9+, TypeScript 5.1+.

If something contradicts your instincts, the bundled docs win. Read them.

## 5. The design system — `../docs/OXOT-DESIGN-SYSTEM.md` IS THE LAW

**Read it before you write a line of markup.** Machine-readable companion:
`../docs/OXOT-DESIGN-SYSTEM.css`. Both are sourced from the owner's *"OXOT
Conformity — Design System Spec"* with file:line citations — not from anyone's
taste. `CLAUDE.md` §7e is the short form. The six rules people break:

1. **Tokens only. Never a raw colour.** No hex, no literal `rgb()`/`hsl()` in a
   component. The old site accumulated **41 contrast failures on one page** from
   a single hard-coded `#e8700a`.
2. **Three oranges, three jobs.** `--primary` (`28 90% 55%`) is an **accent
   fill** — ~3.0:1, fails AA under 24px. Small orange **text** →
   `text-primary-ink`. Text **on** an orange fill → `text-primary-foreground`,
   which is dark navy `210 50% 12%`, **not white**. Eyebrows → `.oxot-kicker`.
3. **Headings by ROLE, never by page.** `.h-page` (editorial serif, normal
   weight, exactly one per page) · `.h-section` · `.h-sub` · `.h-card` ·
   `.h-micro`. **Never a raw `text-{size}` on a heading.** 25+ files each
   picking their own size between `text-2xl` and `text-7xl` is the documented
   failure this replaces — and the spec names oversized improvised headings as
   a real, measurable part of why the old site looked worse.
4. **Shadows are two-layer and theme-tinted** — a flat 2px shelf under a soft
   blur; warm `hsl(28 20% 15%)` in light, near-opaque black **plus an inset top
   highlight** in dark. Never Tailwind's default `shadow-md`.
5. **Layout lives in `.oxot-canvas`.** Never a bespoke `mx-auto max-w-*` page
   wrapper. Reading measure goes on an inner element (`.prose-measure`).
6. **Motion has three fixed durations** — buttons 200ms · cards 300ms ·
   `.cta-lift` 150ms — on `cubic-bezier(0.22, 1, 0.36, 1)`. Transform and
   opacity only; never layout properties. Every hover has a `:focus-visible`
   twin. Global reduced-motion is guarded in CSS **and** by
   `<MotionConfig reducedMotion="user">`.

**Non-negotiable setup (owner, 2026-08-07):** shadcn/ui at `new-york` /
`neutral` / `cssVariables: true` · `defaultTheme="dark"` · the Card hover-lift
className in `components/ui/card.tsx`. Details in §0 of the design-system doc.

Typography: Newsreader (display — applied to every heading globally, with
`tracking-tight`), Instrument Sans (UI/body), IBM Plex Mono (anything the reader
should parse as **data** — counters, spec keys, `SCOPE`, `01`; use `.mono-label`).
Self-hosted via `next/font` — a deliberate, documented deviation from the spec's
Google Fonts `@import`, required by `OXOT-STYLEGUIDE` §3.1 for GDPR.

## 6. Visualisation is the point, and it must survive without JS

The owner asked for advanced visualisation. The bar: a visual must **carry an
argument the prose cannot**, not decorate one.

- **Server-render the data.** An SVG built from real numbers in the markup beats
  a chart library that paints after hydration.
- **Never ship content at `opacity: 0`.** The previous site rendered its h1 and
  all four proof rows invisible until hydration, on the page whose whole job is
  the first four seconds. Anything above the fold must be correct in the HTML.
- Motion is enhancement. `prefers-reduced-motion` is respected globally in
  `globals.css`; do not defeat it.
- Both themes. Every stroke, fill and label from tokens.

Candidates, each tied to an argument already in the handover: the three roads
(Modules A / B+C / H, and **why Road A is shut**); the CRA timeline (five dates,
each against its obligation); the seven-layer twin; the countable obligations;
the NOW / NEXT / NEVER decision output.

## 7. Verify, do not assert

- `npx tsc --noEmit` clean, `npm run build` succeeds.
- The dev server runs on **http://localhost:3100**.
- Check **both themes** and **390 / 834 / 1440 / 2560**.
- Check `::before`/`::after`/`::placeholder` contrast **by hand** — automated
  passes cannot see pseudo-elements, and two real AA failures hid there.
- Every link resolves 200 with no redirect hop.

## 8. Both languages, or neither

**Superseded.** This section used to say "English only, routes unprefixed, Dutch
is additive later." Dutch has landed; the instruction is now the opposite of the
truth and is replaced.

- **Routes are locale-prefixed** — `/en/...` and `/nl/...`, per CLAUDE.md §3.
  There is no unprefixed route: `src/proxy.ts` negotiates `Accept-Language` and
  redirects. **The file is `proxy.ts`, not `middleware.ts`** — the old name
  silently never runs in Next 16.
- **Never hard-code a locale into a URL.** Use `localePath(locale, PATHS.x)`.
  A literal `href="/cra"` bounces a Dutch reader out to the proxy and back.
- **Sentences live in `src/i18n/{en,nl}.ts`.** `en.ts` defines the shape and
  `nl.ts` must satisfy it, so a missing Dutch string fails the build.
- **Facts live in a claim sheet with `nl` required**, read through
  `say(claim, locale)`. Never `.en` — that is how an English sentence reaches a
  Dutch page.
- **Copy bound to data** (a timeline row's label, a table's zone name) is
  `Bilingual` **next to its data**, read with `pick(value, locale)`, so the date
  and both translations move in one edit.
- **Compose with `fmt(template, vars)`,** never by concatenating fragments —
  Dutch does not always agree with English word order.
- **Every page declares `localeAlternates(locale, path)`.** Not the layout:
  metadata inherits, and a canonical set once at the layout made every page
  claim to be the homepage.
- **Dutch runs 15–20% longer, and its compounds are unbreakable.** Cap widths
  in `ch`, not pixels. `hyphens: auto` is on globally and needs `<html lang>` to
  pick the right dictionary; mono and code are exempt.
- **Measure both locales.** `node scripts/measure.mjs /en/... /nl/...` — the
  one overflow bug on this site appeared in Dutch only.

## 9. Be a problem solver

If the page needs an artefact that does not exist and it is **OXOT's own
document**, compose it and mark it clearly. Do **not** invent facts about
registries, customers, certifications or third parties. If you write a line that
is not in `claims.ts`, say so in your report and justify it.

Refuse with reasoning if an instruction here is wrong. Three builders improved
the previous project by refusing something — inventing a KvK number, promoting
one founder over another, and reusing a headline that vision §5 says must not
repeat.
