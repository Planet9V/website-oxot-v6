# Draw.io Asset & Stencil Reference Library

## Overview
This library contains **9532 converted vector & raster asset icons** from the Draw.io / mxGraph open-source ecosystem, fully structured and ready for direct use in React, Next.js, and web visualizers.

## Contents
1. **[`DRAWIO_ASSET_REGISTRY.md`](./DRAWIO_ASSET_REGISTRY.md)**: Searchable visual catalog indexed by library, domain, and file path.
2. **[`drawio_asset_registry.json`](./drawio_asset_registry.json)**: Machine-readable JSON manifest containing all metadata, formats, and paths.
3. **[`drawio_asset_registry.csv`](./drawio_asset_registry.csv)**: CSV spreadsheet export for tabular lookups and sorting.
4. **[`drawio-icon.tsx`](./drawio-icon.tsx)**: Reusable React / Next.js component for rendering any icon.
5. **[`libraries/`](./libraries/)**: Categorized directory holding all vector SVG and PNG assets.

## Core Libraries Included
- **Cisco & Cisco SAFE**: 300+ network and cybersecurity architecture icons.
- **P&ID (Process Piping & Instrumentation)**: 400+ ISO/DIN valves, pumps, compressors, and instruments.
- **Electrical & Grid**: Substations, transmission lines, relays, and meters.
- **Server Racks**: Front/rear elevations for HPE Aruba, Cisco, Dell, IBM, F5 Big-IP, and APC.
- **Cloud Architecture**: Complete AWS4, Azure (MSCae & Azure 2), Google Cloud (GCP2), IBM Cloud, and Kubernetes sets.
- **Virtualization & Backup**: Veeam 2D/3D (580 assets) and VMware VVD.
