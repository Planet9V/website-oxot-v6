# Image reference library

Raw source images from the OXOT design/asset library. Most were promoted to `public/images/` root so they're reachable at the site's normal image path; the handful left here have a filename that already exists elsewhere in `public/images/` (a different, usually processed or renamed, version of the same source) — kept in this subfolder instead of overwriting the existing one, still reachable at `/images/reference-library/<filename>`.

For the images actually in use on the live site, see `src/components/**/content*.ts` (search for `/images/...` paths).
