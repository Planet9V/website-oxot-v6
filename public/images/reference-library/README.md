# Image reference library

Raw source images from the OXOT design/asset library — not all of these are wired into a live page. They're kept here, in `public/`, so every image is directly reachable by URL (`/images/reference-library/<filename>`) for reference, reuse, or a future page build, rather than sitting in an un-served source folder.

For the images actually in use on the live site, see `src/components/**/content*.ts` (search for `/images/...` paths) and the theme-variant pairs already promoted to `public/images/` root (e.g. `cdt-architecture-dark.png` / `cdt-architecture-light.png`).
