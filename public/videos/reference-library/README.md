# Video reference library

Raw source videos from the OXOT design/asset library. Most were promoted to `public/videos/` root so they're reachable at the site's normal video path; the three left here (`CDT_arch_motion.mp4`, `OXOT_2_pane_rotate.mp4`, `curve_dark.mp4`) share a filename with a video already in use under `public/videos/cdt2/` — kept in this subfolder instead of duplicating or overwriting the in-use one, still reachable at `/videos/reference-library/<filename>`.

For videos actually in use on the live site, see `public/videos/cdt2/` and the `Cdt2*Media.tsx` components in `src/components/cdt2/` (image-then-video crossfade pattern).
