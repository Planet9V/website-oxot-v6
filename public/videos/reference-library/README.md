# Video reference library

Raw source videos from the OXOT design/asset library — not all of these are wired into a live page. They're kept here, in `public/`, so every video is directly reachable by URL (`/videos/reference-library/<filename>`) for reference, reuse, or a future page build, rather than sitting in an un-served source folder.

For videos actually in use on the live site, see `public/videos/cdt2/` and the `Cdt2*Media.tsx` components in `src/components/cdt2/` (image-then-video crossfade pattern).
