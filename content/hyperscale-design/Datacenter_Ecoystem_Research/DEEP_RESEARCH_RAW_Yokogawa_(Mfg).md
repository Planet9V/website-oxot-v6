### Product Security Function and PSIRT

#### Vulnerability Disclosure and Response Process

Yokogawa established a **formal Vulnerability Handling Policy** (established prior to 2018) with **four-stage lifecycle**: [[60]](https://www.yokogawa.com/ph/solutions/products-and-services/lifecycle-services/safety-and-security/announcements/vulpolicy/) [[61]](https://www.yokogawa.com/us/solutions/products-and-services/announcements/vulpolicy/)

| Stage | Timeline | Action |
|---|---|---|
| **1. Acceptance** | 1–2 business days | Acknowledge vulnerability receipt; assign CVE number; assess severity (CVSS scoring) |
| **2. Preparation** | Days/weeks (varies by severity) | Develop patch/workaround; coordinate with affected customers; validate fix |
| **3. Countermeasures** | Upon availability | Release security advisory (Yokogawa Security Advisory Report — YSAR); publish patch; provide workaround for unpatched environments |
| **4. Information Offering** | Post-release | Publish detailed security guidance; coordinate with CISA for ICS-CERT advisories [[1]](https://www.yokogawa.com/library/resources/white-papers/yokogawa-security-advisory-report-list/) [[2]](https://www.cisa.gov/news-events/ics-advisories/icsa-26-057-09) [[3]](https://www.cisa.gov/news-events/ics-advisories/icsa-26-041-01) [[4]](https://www.cisa.gov/news-events/ics-advisories/icsa-26-092-02) [[5]](https://www.cisa.gov/news-events/ics-advisories/icsa-24-172-01) |

[[60]](https://www.yokogawa.com/ph/solutions/products-and-services/lifecycle-services/safety-and-security/announcements/vulpolicy/) [[61]](https://www.yokogawa.com/us/solutions/products-and-services/announcements/vulpolicy/)

#### CVE Numbering Authority Status

**Implication:** Vulnerability-to-disclosure cycle shortened from 6–12 months (third-party CNA) to **2–4 months** (Yokogawa as direct CNA), **demonstrating commitment to transparency and faster security updates**. [[7]](https://www.yokogawa.com/news/briefs/2023/2023-10-25)
