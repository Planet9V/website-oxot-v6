## 10. Security Incidents and Vulnerabilities: Last 36 Months (April 2023–June 2026)

### Category A: e-STUDIO Multi-Function Printer Vulnerability Disclosure (40 CVEs)

#### **Overview and Timeline**

The most significant and publicly disclosed security incident affecting Toshiba products involves **40 separate vulnerabilities** in the e-STUDIO Multi-Function Printer (MFP) family [[26]](https://cybersecuritynews.com/toshiba-mfp-40-vulnerabilities/) [[28]](https://pierrekim.github.io/blog/2024-06-27-toshiba-mfp-40-vulnerabilities.html) [[49]](https://seclists.org/fulldisclosure/2024/Jul/1).

- **Discovery Timeline**: Research and testing conducted March–May 2023
- **Initial Report**: June 14, 2023 (confidential disclosure to Toshiba)
- **Public Disclosure**: June 27–July 1, 2024 (approximately 13 months after initial report, allowing time for patch development)
- **Researcher**: Pierre Kim (independent security researcher, methodology: blackbox, fully remote testing)
- **Affected Model Count**: **103 different e-STUDIO MFP models** across generations (see detailed model list below)

#### **Affected Models (Complete List)**

The 40 CVEs impact the following 103 e-STUDIO model variants:

**High-Capacity Series (8000+ pages/month)**: 2021AC, 2521AC, 2020AC, 2520AC, 2025NC, 2525AC, 3025AC, 3525AC, 3525ACG, 4525AC, 4525ACG, 5525AC, 5525ACG, 6525AC, 6525ACG

**Mid-Capacity Series (3000–8000 pages/month)**: 2528A, 3028A, 3528A, 3528AG, 4528A, 4528AG, 5528A, 6528A, 6526AC, 6527AC, 7527AC, 6529A, 7529A, 9029A

**Legacy/Discontinued (2010s)**: 330AC, 400AC, 2010AC, 2110AC, 2510AC, 2610AC, 2015NC, 2515AC, 2615AC, 3015AC, 3115AC, 3515AC, 3615AC, 4515AC, 4615AC, 5015AC, 5115AC

**Color Series (Compact/Desktop)**: 2018A, 2518A, 2618A, 3018A, 3118A, 3018AG, 3518A, 3518AG, 3618A, 3618AG, 4518A, 4518AG, 4618A, 4618AG, 5018A, 5118A

**High-Performance/Specialty**: 5516AC, 5616AC, 6516AC, 6616AC, 7516AC, 7616AC, 5518A, 5618A, 6518A, 6618A, 7518A, 7618A, 8518A, 8618A

**Entry-Level (Smaller Organizations)**: 2000AC, 2500AC, 2005NC, 2505AC, 3005AC, 3505AC, 4505AC, 5005AC, 2008A, 2508A, 3008A, 3008AG, 3508A, 3508AG, 4508A, 4508AG, 5008A, 5506AC, 6506AC, 7506AC, 5508A, 6508A, 7508A, 8508A

**Low-Page-Count/SOHO**: 3508LP, 4508LP, 5008LP

#### **Vulnerability Taxonomy and Technical Details**

| CVE Range | Vulnerability Class | CVSS Score | Technical Summary | Attack Vector |
|---|---|---|---|---|
| **CVE-2024-27141 through CVE-2024-27142** | XML External Entity (XXE) Injection | Medium-High | Pre-authenticated attacker can cause denial of service (DoS) by uploading malicious XML documents | Network, no credentials required |
| **CVE-2024-27143 through CVE-2024-27144** | Remote Code Execution (RCE) | Critical (8.8–9.8) | Pre-authenticated attacker can execute arbitrary commands as root or apache user; allows upload of .py Python modules and arbitrary system binaries | Network, no credentials required |
| **CVE-2024-27145 through CVE-2024-27153** | Local Privilege Escalation (LPE) | High | Insecure snmpd configuration, unsafe use of LD_PRELOAD, LD_LIBRARY_PATH injection, PATH manipulation, setuid/setgid binaries without proper validation | Local access required (must have shell access to MFP) |
| **CVE-2024-27154 through CVE-2024-27157** | Sensitive Data Disclosure | Medium | Authentication credentials and session identifiers logged in cleartext in web server logs; accessible to low-privilege users | Local file access |
| **CVE-2024-27158** | Hardcoded Credentials (Root) | Critical (9.8) | Default root user password ("toshiba123") identical across all e-STUDIO MFPs; unchanged since 2017 firmware | Physical or remote SSH access if port exposed |
| **CVE-2024-27159 through CVE-2024-27161** | Hardcoded Encryption Keys | Critical (9.8) | Master encryption key "1048toshibatec" embedded in all firmware images; used to encrypt sensitive configuration and passwords | Firmware reverse engineering (static analysis) |
| **CVE-2024-27162** | Cross-Site Scripting (XSS) – DOM-Based | Medium | Unvalidated user input in web interface reflected in DOM without sanitization; allows JavaScript injection in administrator browser | Network, authenticated admin account required |
| **CVE-2024-27163 through CVE-2024-27165** | Hardcoded Credentials (Services) | High | WebDAV username "toshiba" hardcoded; telnetd credentials embedded; FTP credentials in configuration files | Remote access if services exposed |
| **CVE-2024-27164** | Telnet Daemon Credentials | High | telnetd service runs with hardcoded credentials; allows unauthenticated shell access | Remote (TCP port 23, rarely filtered) |
| **CVE-2024-27166 through CVE-2024-27171** | Weak Cryptography & Insufficient Entropy | High | Use of outdated cipher suites (DES, MD5), weak random number generation, improper certificate validation in HTTPS communications | Man-in-the-middle (MITM) attack |
| **CVE-2024-27170** | WebDAV Hardcoded Credentials | High | WebDAV interface (file upload/download) protected only by hardcoded username "toshiba" | Network file access |
| **CVE-2024-27172** | Command Injection / OS Command Execution | Critical (9.8) | User-controlled input passed unsanitized to shell commands; allows RCE via special characters (backticks, `$()`, semicolons) | Network, may require authentication context |
| **CVE-2024-27173 through CVE-2024-27178** | Arbitrary File Upload → RCE | Critical (9.8) | File upload functionality allows upload of executable files (.py, .sh, .bin); no file type validation; uploaded files can be executed by web server | Network, authenticated access (but see hardcoded creds above) |
| **CVE-2024-27175** | Local File Inclusion (LFI) | High | Path traversal in file serving function; allows reading arbitrary files from MFP filesystem (/etc/passwd, /etc/shadow, configuration files) | Network, may require low-privilege access |
| **CVE-2024-27179** | Session Token Disclosure | Medium | Session tokens exposed in log files, browser cache, or through HTTPS certificate misuse | Forensic analysis, physical access to logs |
| **CVE-2024-27180** | Time-of-Check-Time-of-Use (TOCTOU) Race Condition | Medium | Authentication check and resource access are separated in time; attacker can race between checks to bypass security controls | High-speed network, precise timing required |

**Key Observations**:
- **Hardcoded Credentials**: The most severe vulnerabilities stem from credentials embedded in firmware (root password "toshiba123" unchanged since 2017, encryption key "1048toshibatec", WebDAV "toshiba", telnetd credentials)
- **Authentication Bypass**: Multiple pre-authenticated RCE paths mean an attacker with network access (no credentials) can achieve full system compromise
- **Logging Failures**: Multiple CVEs involve secrets (passwords, session tokens) being written to logs in cleartext
- **Age and Pervasiveness**: These vulnerabilities affected MFP models spanning approximately 15 years (2009–2024), indicating long-standing architectural issues

#### **Patch and Remediation Status**

- **Patch Availability**: Toshiba released **security firmware updates** for supported e-STUDIO models [[50]](https://www.toshibatec.com/information/20240531_01.html)
- **Toshiba Security Advisory** (official): Published June 14, 2024 on Toshiba PSIRT website [[27]](https://www.global.toshiba/ww/cybersecurity/corporate/psirt.html)
- **Affected vs. Supported Models**: Certain legacy models (marked "discontinued" or "end-of-life") may not receive patches; organizations operating these models must consider retirement or isolation
- **CVSS Scoring**: Only one specific CVSS vector was detailed in research (CVE-2024-3496: **8.8 HIGH**, CVSS:3.1/AV:A/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H); complete CVSS matrices for all 40 CVEs available in Toshiba's technical advisories

#### **Operational Impact and Risk Assessment**

For organizations operating e-STUDIO MFPs:
- **Attack Surface**: Any MFP connected to corporate network, adjacent networks (via WiFi, guest network), or internet-facing is at risk
- **Blast Radius**: Compromise of a single MFP can serve as pivot point to access networked storage, email servers, or employee devices (print job interception)
- **Data Exfiltration Risk**: Hardcoded credentials and file upload vulnerabilities enable theft of confidential documents sent to printer
- **Business Continuity**: MFP compromise can disable printing for entire organization (ransomware, configuration wipe)

  - **PR:N** (No Privileges): Unauthenticated attacker

  - **S:U** (Unchanged Scope): Impact limited to the vulnerable component (MFP)
  - **C:H** (High Confidentiality Impact): Attacker can read all data on MFP
  - **I:H** (High Integrity Impact): Attacker can modify configuration, documents, logs
  - **A:H** (High Availability Impact): Attacker can disable MFP or delete data

- **Re-Compromise**: Attacker regained control of polyfill.io domain in May 2026
- **Toshiba Symptoms**: Suspicious login prompts detected on Toshiba.com beginning approximately **June 1, 2026** [[61]](https://www.bleepingcomputer.com/news/security/suspicious-polyfill-login-prompts-pop-up-on-toshiba-muji-websites/) [[62]](https://www.squaredtech.co/polyfillio-is-back-and-its-trapping-users-with-fake-login-prompts)

- **Duration**: Approximately 5 days (June 1–5, 2026) before remediation [[61]](https://www.bleepingcomputer.com/news/security/suspicious-polyfill-login-prompts-pop-up-on-toshiba-muji-websites/)

**Technical Details:**
- **Attack Vector**: Malicious JavaScript injected into legitimate Toshiba.com pages via compromised polyfill.io CDN
- **Payload**: Fake login screens (JavaScript DOM manipulation) capturing credentials entered by unsuspecting users
- **Blast Radius**: 6+ organizations affected (Toshiba, Muji, Zojirushi, FiNC, Ishiyaku Publishers, Hobonichi, Samsung)

**Data Breach Status:**
- **Confirmed Breach**: NO — Toshiba advisory advised password changes but did not confirm data breach
- **Credentials Potentially Compromised**: YES — Any user who entered credentials into fake login prompts
- **Root Cause**: Incomplete remediation of 2024 polyfill.io compromise; failure to fully remove or sandbox the library

**Incident Response Quality:**
- **Detection**: Toshiba detected the issue in a timely manner
- **User Notification**: Public advisory issued within 24 hours of discovery
- **Remediation**: Library removed or replaced; users advised to change passwords
- **Post-Incident**: No public incident report; remediation details not fully disclosed

**B2B Sales Impact**: This incident demonstrates that even large, security-conscious organizations can fall victim to supply chain attacks via third-party dependencies. It underscores the importance of Software Bill of Materials (SBOM) transparency and dependency scanning tools.
