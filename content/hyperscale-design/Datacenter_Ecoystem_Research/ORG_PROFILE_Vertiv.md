## PAGE 3 OF 6: OT SECURITY — PRODUCT CYBERSECURITY ANALYSIS

### 3.1 IntelliSlot Network Interface — THE PRIMARY OT ATTACK SURFACE

The **IntelliSlot RDU120** is Vertiv's primary network management card installed in all major Liebert UPS and precision cooling products. It enables SNMP, HTTPS, REST API, Modbus TCP, and SSH management of critical power infrastructure.

| Product | Part Number | Protocols | Firmware Version | Certification | Notes |
|---|---|---|---|---|---|
| **IntelliSlot RDU120** | 1P-RDU120 | SNMPv1/v2/v3, REST API, SSH, TLS, Modbus TCP | v5.x | **IEC 62443-4-2** | Certificate posted ~mid-2025 (LinkedIn: Massimo Zampieri, Vertiv EMEA) |
| **IntelliSlot Web** (legacy) | RDU101/102 | SNMPv1/v2, HTTPS | v2.x | None | Legacy — CVE-exposed |
| **iCOM-S Controller** | — | Ethernet, REST | v4.x | Under assessment | Cooling management; CRA scope |
| **Geist Rack PDU** | Various | SNMPv3, REST, TLS | Current | None confirmed | Rack PDU — CRA class I scope |
| **Avocent ACS** | ACS800/8000 | SSH, HTTPS, Telnet (legacy) | Current | None confirmed | Console server — CRA scope |
