### Vulnerability Management Policy Framework

Milestone publishes a formal **Vulnerability Management Policy** [[45]](https://doc.milestonesys.com/cybersecurity/pdf/en-US/Milestone_VulnerabilityManagement_en-US.pdf) [[46]](https://www.milestonesys.com/resources/content/articles/vulnerability-management/) [[48]](https://doc.milestonesys.com/latest/en-US/portal/htm/chapter-page-cve-vulnerabilitymanagementpolicy.htm) defining:

**Discovery phase**:
- Internal security testing and code reviews
- External researcher submissions via online form
- Third-party security assessments

**Assessment phase**:
- CVSS scoring (Common Vulnerability Scoring System v3.1)
- Severity classification (Critical, High, Medium, Low)
- Attack vector analysis (network, local, physical, adjacent)
- Exploitation likelihood assessment

**Disclosure phase**:
- **90-day responsible disclosure window** from researcher report to public disclosure
- Vendor coordination with affected parties prior to public announcement
- CVE Record publication on MITRE/NVD and company website
- Release notes and patch availability guidance

**Remediation phase**:
- Security patch development and testing
- Integration into regular software update cycles (XProtect targets 3 releases per year) [[49]](https://www.axis.com/dam/public/permalink/73295/recommended-cybersecurity-policies-for-deploying-and-maintaining-axis-and-milestone-systems-eguide-en-US_InternalID-73295.pdf)
- Customer notification via security advisories

**Limitations**:
- No encrypted reporting channel (PGP/GPG key) published for confidential vulnerability submission
- No vulnerability compensation program or bug bounty documented [[45]](https://doc.milestonesys.com/cybersecurity/pdf/en-US/Milestone_VulnerabilityManagement_en-US.pdf)
- No dedicated security contact email published (general compliance@milestonesys.com used) [[48]](https://doc.milestonesys.com/latest/en-US/portal/htm/chapter-page-cve-vulnerabilitymanagementpolicy.htm)

### Patch and Update Cadence

[[49]](https://www.axis.com/dam/public/permalink/73295/recommended-cybersecurity-policies-for-deploying-and-maintaining-axis-and-milestone-systems-eguide-en-US_InternalID-73295.pdf)
