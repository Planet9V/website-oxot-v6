# 3D facilities — source material

Raw/working 3D models and Blender procedure docs for the hyperscale campus, hall, and rack — kept as reference, not servable web assets.

**Not the same files as `public/models/`.** The curated, production `_hq` GLBs actually used by the site (`hyperscale_campus_hq.glb`, `hyperscale_rack_hq.glb`, `hyperscale_hall_hq.glb`, `plc_s71500f_hq.glb`) live in `public/models/`. The `.glb`/`.obj`/`.mtl` files in this folder are earlier/raw versions from the modeling process, kept here for reference (e.g. `instructions_blender.md`, `3D Model Generation Procedure`), not a second copy to serve.
